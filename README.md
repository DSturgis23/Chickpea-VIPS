# Chickpea VIPs

Phone web app for tagging SevenRooms guests as VIP without logging into SevenRooms.
Tags go on the guest's **profile** (category "VIP client type"), so they follow the
guest to every booking at every pub.

## Using it
Open the site on your phone → enter PIN → **Share → Add to Home Screen** (iPhone) or
**⋮ → Add to Home screen** (Android). Search a name or email, tap **Mark VIP**.
To remove, tap the gold **★ VIP** chip twice.

The same guest often has several profiles (old imports). They're listed busiest first —
the one with the most visits and an email/phone is usually the live one.

## Settings (Render → Environment)
| Variable | What |
|---|---|
| `SR_CLIENT_ID`, `SR_CLIENT_SECRET` | SevenRooms API key (same as the dashboards) |
| `APP_PIN` | PIN to open the app |
| `SECRET_KEY` | auto-generated by Render |
| `VIP_TAGS` | tags offered, comma-separated, e.g. `VIP,Investor,Press` — each must already exist in SevenRooms under "VIP client type" |

## How the SevenRooms side works
- Search: `GET /clients?venue_group_id=…&name=…` (or `email=`). The search index lags,
  so each match is re-read with `GET /clients/{id}` for current tags.
- Tag: `POST /clients/{id}` with `add_tags` / `remove_tags` = `"VIP client type:VIP"`.
- SevenRooms returns 200 even for formats it ignores, so every change is read back and
  only reported as done if the tag really moved. Changes are logged (Render → Logs, `TAG`).

## Run locally
```
set SR_CLIENT_ID=… & set SR_CLIENT_SECRET=… & set APP_PIN=…
python app.py      # http://localhost:5050
```
